# The Woman Who Made Me

An immersive birthday story for Ma, told by her son in thirteen chapters —
from the nights he was a sick little boy, through the notebook she taught him
to write in, the lessons she learned at midnight to teach him the next day, to
a letter and a birthday cake at the end.

## Run it

```bash
npm install
npm run dev          # http://localhost:5173
```

Build a finished, static copy (in `dist/`) that can be hosted anywhere (Netlify,
Vercel, GitHub Pages, or opened via `npm run preview`):

```bash
npm run build
npm run preview
```

No backend, accounts, API keys, microphone or location access are needed.

## Make it yours

| What | Where |
|---|---|
| How you address her ("Ma" / "Ammi"), your sign-off, your name | `src/content/settings.ts` |
| Every word of every chapter, the letter, the interludes | `src/content/story/` (one file per chapter) |
| Photographs, captions, alt text | `src/content/photos.ts` + `photos/` — see [docs/PHOTO-MANIFEST.md](docs/PHOTO-MANIFEST.md) |
| Music | `public/audio/` — see [public/audio/README.md](public/audio/README.md) |
| Show or hide "to add" placeholders | `settings.placeholders` |

### Details still to add

Some details were left as clearly marked placeholders rather than guessed:

- **Chapter 06** — her favourite dishes, the dish you always ask for, her
  special-occasion dish, a favourite film, a song she loves, a cricket memory,
  family sayings, funny family moments (`src/content/story/06-could-do-everything.ts`).
  Replace each `ph('…')` with a plain string.
- **Photos** — a school photo, a childhood photo from home, Ma cooking, and a
  recent photo of the two of you (the ideal final image).

While you run `npm run dev`, placeholders appear as dashed "To add" labels so they
are easy to find. In the built site they are hidden automatically, so nothing
unfinished is ever shown to her.

## Accessibility & comfort

- Full keyboard support; visible focus; the chapter list is a proper dialog.
- Respects the "reduce motion" system setting. To preview that version, add
  `?reduced-motion` to the URL (e.g. `http://localhost:5173/?reduced-motion`).
- Music never starts on its own — only after "Begin our story" with Sound on —
  and can be paused or muted at any time.
- Printing the page (or "Keep this letter" → "Print or save as PDF") prints only
  the letter, cleanly typeset.

## How it is built

React 19 + TypeScript + Vite, plain CSS with design tokens, GSAP (ScrollTrigger,
SplitText, DrawSVG) for scroll-linked storytelling, and a small generated ambient
score using the Web Audio API. See [docs/DESIGN-SYSTEM.md](docs/DESIGN-SYSTEM.md).

```
photos/               original photographs (source)
public/images/        optimised WebP photos (generated by `npm run photos`)
public/audio/         optional music file
src/content/          everything you would edit: settings, story text, photo manifest
src/chapters/         one folder per chapter scene
src/components/       shared pieces: Photo, Thread, Reveal, Botanical, nav, lightbox…
src/lib/              GSAP setup, motion preferences, navigation helpers
src/audio/            music engine and controls
scripts/              photo optimisation
```
